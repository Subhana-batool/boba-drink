🧋 BobaDrink — Animated Bubble Tea Showcase

A modern, single-page React frontend project featuring a creative bubble tea theme, eye-catching visuals, smooth animations, and a stylish user interface.

🌐 Live Demo: boba-drink.vercel.app

✨ Features

🧋 Bubble tea-inspired visual design

🎬 Smooth animations and transitions

🎨 Modern and engaging user interface

📱 Responsive frontend layout

⚡ Fast development with React and Vite

🌐 Deployed on Vercel

🛠️ Tech Stack

React

Vite

JavaScript

CSS

🎯 Project Purpose

BobaDrink is a frontend-only creative project designed to explore animation, visual storytelling, and modern web design through a bubble tea-themed experience.

This project is a single-page showcase, not a complete online ordering system.
